Inside the local agent.

Follow a source from intake to human review. Explore all 18 layers—Layer 0 is the behaviour contract; Layers 1–17 describe the system. A layer is a responsibility, not a claim of completion.

Current engineering evidence: the private loopback API was tested on 127.0.0.1:8765. It creates deterministic review artifacts. No reasoning provider or computer-use executor is connected. This page is an architecture guide, not a live control panel.
01 · Submit a sourcePublic/toy text enters the local API. Host, origin, credential and size checks run first.
02 · Build a review runDeterministic code extracts source-presented claims and links them to the retained source.
03 · Inspect and judgeThe operator checks relevance, evidence, context and proposed actions. A machine confidence is not your verdict.
04 · Retain the decisionSeparate review APIs keep judgments. Promotion to approved memory requires another governance check; HTTP does not do it.
