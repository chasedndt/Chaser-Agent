# Chaser Agent canonical asset release 1.0.0

Release date: 2026-09-02

This is the first canonical consumer contract for the operator-approved Chaser Agent identity. It promotes two immutable, visually approved source sets without rewriting their provenance:

- Canon/Core `1.0.0-rc.1`: production Blender source, GLB, transparent masters, avatars, silhouettes, model sheets, review stills, optimized web hero media, and clean turntable.
- Runtime Format Pack pass 02: ten separate state profiles, visor glyphs, UI badges, 64 px icons, 32 px icons, semantic colour tokens, and accessibility text.
- Public Identity Pack v1.0.0: deterministic GitHub, social, X, Discord, documentation, and press-ready exports.

## Consumer rules

- Use clean camera renders only on public surfaces.
- Keep state assets as separate files; do not flatten the ten states into one source image.
- Use semantic tokens and alt text from the runtime-format semantics file.
- Do not redraw, re-colour, distort, crop through the head, or place provenance VFX over the face.
- Do not treat this release as proof that the expressive rig, body motion, audio, or provenance VFX is complete.
- Downstream websites consume this version; they do not become the editable source of truth.
