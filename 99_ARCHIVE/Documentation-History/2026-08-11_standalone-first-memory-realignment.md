- Date: 2026-08-11

## Historical change

This pass moved Chaser agent from a ChaseOS-dependent product narrative and deterministic design-flavoured scaffold into an executable standalone-first P0.1 foundation. The core now has explicit dependency protocols, profile-isolated deterministic review, immutable human review, local governance, append-only SQLite memory, lexical retrieval, provenance graph queries, an inactive optional ChaseOS adapter, and an exact public test-matrix export.

## Why it mattered

The prior harness created safe review artifacts but did not capture human decisions or carry accepted evidence into governed local state. Website-design language also leaked into the default builder. P0.1 turns the review opportunity into a local product workflow while preserving the rule that generated output cannot approve itself.

- Eval visibility, source-card schema/spec, memory docs, human-review rubric, dataset/eval classification, and AI-engineering learning map.
